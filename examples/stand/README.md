# Снимок проверки стенда

Сервер читает один JSON-файл из пути `TESTOPS_STAND_REPORT`. Производитель
публикует файл атомарной заменой после завершения проверки. Результат
импортируется только в сессию с совпадающим идентификатором стенда.
Для каждой новой проверки нужен новый `check_id`. Повторный импорт прежнего
идентификатора в ту же сессию возвращает сохранённую запись.

| Поле | Тип и содержание |
| --- | --- |
| `check_id` | UUID или идентификатор из 16–36 латинских букв, цифр и дефисов |
| `bench` | Идентификатор стенда |
| `name` | Название проверки |
| `outcome` | `passed`, `failed` или `inconclusive` |
| `note` | Текстовое наблюдение, до 1 000 символов |
| `measured_at` | Время измерения с часовым поясом в ISO 8601 |

`scripts/demo-stand.py` формирует снимок на основе заданного демонстрационного
времени установления вызова. Для реального стенда этот формат должен выдавать
его адаптер. Повторный тест запускается в самом стенде или настроенном CI.
